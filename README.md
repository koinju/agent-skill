# Koinju Agent Skill

A [Claude Code](https://claude.com/claude-code) skill for working with the **Koinju** multi-exchange crypto market-data API ([koinju.io](https://koinju.io)). Helps Claude discover, query, and integrate Koinju data — REST endpoints, ClickHouse SQL, OHLCV / trade / option-chain / funding-rate / market-discovery — into research, backtesting, and production pipelines.

This repository is a **public mirror**: every commit is generated from Koinju's internal `dag` repo by CI. Don't open PRs here; report issues at [support@koinju.io](mailto:support@koinju.io) or file in the Koinju docs feedback channel.

## Install

```bash
git clone https://gitlab.com/koinju-public/agent-skill.git ~/.claude/skills/koinju
```

Then in any Claude Code session, the skill triggers automatically on Koinju- and crypto-data-related queries. See `SKILL.md` for the workflow and `references/` for the bundled documentation.

## What's inside

- **`SKILL.md`** — entry-point: workflow, project-setup logic, migration notes, bundled-resources list.
- **`references/`** — handwritten gotchas + autogenerated catalogs:
  - `auth.md` — credential setup (`KOINJU_*` env vars, `.koinju.env`, dataroom)
  - `data-tables.md` — `Decimal` / IV-units / snapshot-cadence gotchas + per-table notes + live `api.*` schema appendix
  - `rest.md` — discovery rule + jq cookbook + per-tier rate limits + full endpoint catalog from `api/market-data.yaml`
  - `recipes/` — 11 CI-validated cookbook recipes (Bollinger, Sortino, max drawdown, mean-reversion z-score, historical vol, DCA vs lump-sum, perp funding, spot/perp spreads, cross-exchange arbitrage, OHLCV streaming, correlation) — each pairs a Python implementation with the SQL equivalent and a parity test
  - `optimization.md`, `backtesting.md`, `plotting.md`, `integrations.md`, `bootstrap.md` — depth on perf, strategy workflow, charts, Postgres/Redis plug-in patterns, project-setup fallback
- **`scripts/`** — `setup.sh` (one-shot project bootstrap), `probe-env.sh` (one-line state check), `probe-schema.sh` (live `api.*` DESCRIBE), `welcome_btc_usdt.py` / `plot_option_smile.py` / `backtest_buy_and_hold.py` (runnable demos).
